Fidelity 的開放原始碼轉型：雲端基礎架構與 AI 的演進

摘要

本文探討 Fidelity 在雲端基礎架構和人工智慧 (AI) 領域的開放原始碼轉型之旅。Fidelity 正在逐步從專有解決方案轉向開放原始碼替代方案，以追求成本效益、靈活性以及社區參與。本文將深入介紹 Fidelity 在 Kubernetes、LangChain 和 Helm 等技術上的應用，以及他們如何克服轉型過程中遇到的挑戰，並強調開放原始碼對 Fidelity 未來發展的重要性。

前言

在當今科技快速發展的時代，開放原始碼軟體扮演著越來越重要的角色。Fidelity，作為一家全球領先的金融服務公司，也意識到開放原始碼的價值，並積極推動其在雲端基礎架構和 AI 領域的應用。

技術介紹

1. Kubernetes 的採用

Fidelity 正從 Cloud Foundry 轉向 Kubernetes，利用其開放原始碼特性進行容器管控。Kubernetes 提供高度可擴展、可靠性和彈性的容器化環境，符合 Fidelity 對雲端基礎架構的需求。

  • 挑戰: 從較為簡單的平台轉向 Kubernetes 可能是複雜的，因為 Kubernetes 本身具有較高的學習曲線。
  • 策略:
    • Pakito: 提供類似 CF push 的體驗，吸引部分開發者。
    • ECS Legacy: 一些應用程式已經建立在 ECS 上，使得轉移更加順利。
    • Backstage: 投資工具如 Backstage，簡化 Kubernetes 的知識和使用。
    • 內部開源優勢: 利用內部開源技術，例如 Helm 圖表和庫，簡化開發者流程。
  • 平台: Fidelity 目前使用 Amazon EKS (Elastic Kubernetes Service) 作為其 Kubernetes 平台。

2. LangChain 的應用

Fidelity 利用 LangChain，一個開放原始碼框架，將生成式 AI 能力，例如 ChatGPT，整合到其工作流程中。LangChain 提供了豐富的工具和模組，方便開發者開發和部署基於大型語言模型的應用程式。

3. 混合架構

Fidelity 採用混合架構，結合開放原始碼和雲端平台，例如 Amazon EKS。這種混合架構可以讓 Fidelity 根據不同應用程式的需求選擇最合適的技術方案。

4. 對開放原始碼的貢獻

Fidelity 積極回饋開放原始碼社群，通過程式碼貢獻和支持項目，例如 Helm。這種貢獻精神有助於促進開放原始碼生態系統的發展，並讓 Fidelity 參與到技術創新的前沿。

挑戰與策略

Fidelity 在轉型過程中也面臨一些挑戰，例如管理複雜性和確保安全性。他們通過以下策略來應對這些挑戰：

  • 工具: 使用 Backstage 等工具來簡化 Kubernetes 的管理和使用。
  • 培訓: 培養內部員工的 Kubernetes 和開放原始碼技術專長。
  • 安全: 嚴格執行安全措施，確保開放原始碼軟體的安全性。

結論

Fidelity 的開放原始碼轉型是一個持續進行的過程，他們正在積極探索和應用新的技術，以提升效率、降低成本，並促進創新。開放原始碼將繼續在 Fidelity 的未來發展中扮演重要角色，並推動其在金融科技領域的領先地位。
